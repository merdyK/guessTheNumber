# Игра «Угадай число»

Консольная игра на языке программирования Go, в которой нужно угадать случайное число за ограниченное количество попыток.

## О проекте

Программа загадывает случайное число, а задача игрока — угадать его. В зависимости от выбранного уровня сложности меняются диапазон чисел и количество попыток.

## Возможности

- Три уровня сложности: Easy, Medium, Hard.
- Генерация случайного числа.
- Подсказки: «горячо», «тепло», «холодно».
- Подсказки о том, больше или меньше загаданное число.
- Отображение предыдущих попыток.
- Сохранение истории игр в файл `results.json`.
- Возможность сыграть ещё раз.

## Уровни сложности

| Уровень | Диапазон чисел | Количество попыток |
|:---|:---:|:---:|
| Easy | 1–50 | 15 |
| Medium | 1–100 | 10 |
| Hard | 1–200 | 5 |

## Требования

- Установленный Go версии 1.22 или новее.

## Как запустить игру

Склонируйте репозиторий:

```bash
git clone https://github.com/merdyK/guessTheNumber.git
```

Перейдите в папку проекта:

```bash
cd guessTheNumber
```

Запустите программу:

```bash
go run main.go
```

## Пример работы программы

Ниже приведён пример игрового процесса на уровне Medium. Загаданное число в примере — 42. В реальной игре оно генерируется случайно.

```text

выбери сложность: Easy/Medium/Hard

Игра началась!

Введите число
попытка 1
предыдущие попытки: []
Ты ввёл: 70
холодно
загаданное число меньше

Введите число
попытка 2
предыдущие попытки: [70]
Ты ввёл: 48
тепло
загаданное число меньше

Введите число
попытка 3
предыдущие попытки: [70 48]
```

*Пример демонстрирует победу на третьей попытке. Вывод программы может отличаться в зависимости от случайно загаданного числа и ответов игрока.*

## Сохранение результатов

После завершения игры результат автоматически сохраняется в файл `results.json`. В нём хранятся дата игры, результат и количество использованных попыток.
