# Игра "Угадай число"
Консольная игра на языке программирования Go, в которой нужно угадать случайное число за ограниченное количество попыток.
## О проекте 
Программа загадывает случайное число, а задача игрока — угадать его. В зависимости от выбранного уровня сложности меняются диапазон чисел и количество попыток.
## Возможности 
 - Три уровня сложности: Easy, Medium, Hard.

 - Генерация случайного числа.

 - Подсказки: горячо, тепло, холодно.

 - Отображение предыдущих попыток.

 - Сохранение истории игр в файл results.json.

 - Возможность сыграть ещё раз.
## Уровни сложности
| Уровень | Диапазон чисел | Количество попыток |
|---|---|---|
| Easy | 1–50 | 15 |
| Medium | 1–100 | 10 |
| Hard | 1–200 | 5 |
## Требования

- Установленный Go версии 1.22 или новее.

## Как запустить игру

Склонируйте репозиторий:

git clone https://github.com/merdyK/guessTheNumber.git

Перейдите в папку проекта:

cd guessTheNumber

Запустите программу:

go run main.go

## Пример работы программы

`Игра 'Угадай число'`

`выбери сложность: Easy/Medium/Hard`

`Medium`

`Игра началась!`

`Угадай число от 1 до 100 за 10 попыток`
